Semillas#

La semilla global es SEED = 42, definida una sola vez en src/config.py. La función fijar_semillas la propaga a los generadores de Python y numpy; cada estimador la recibe en random_state (scikit-learn, XGBoost, imbalanced-learn y el modelo original), el muestreador TPE de Optuna en seed y el algoritmo genético la usa tanto en el generador de numpy que crea la población inicial como en el módulo random que emplea DEAP en la selección, el cruce y la mutación. La sensibilidad a la semilla se evaluó explícitamente con cinco semillas (capítulo 6).

from src.analysis import tabla_pliegues
partes = []
for carpeta, tarea in (("clf_calamar", "clasificación"), ("reg_calamar", "regresión"), ("original_calamar", "clasificación")):
    t = tabla_pliegues(carpeta); t["tarea"] = tarea
    partes.append(t)
largo = pd.concat(partes, ignore_index=True)
from src.analysis import cargar_carpeta
params = {(r["modelo"], r["balanceo"], r["optimizador"], r["pliegue"]): json.dumps(r["params"])
          for c in ("clf_calamar", "reg_calamar", "original_calamar") for r in cargar_carpeta(c)}
largo["hiperparametros"] = [params[(a, b, c, d)] for a, b, c, d in zip(largo.modelo, largo.balanceo, largo.optimizador, largo.pliegue)]
largo["semilla"] = SEED
metricas = [c for c in ("pr_auc", "roc_auc", "f1", "precision", "recall", "accuracy", "brier", "rmse", "mae", "r2", "mape") if c in largo]
agg = largo.groupby(["tarea", "modelo", "balanceo", "optimizador"]).agg(
    **{f"{m}_media": (m, "mean") for m in metricas}, **{f"{m}_desv": (m, "std") for m in metricas},
    tiempo_total_s=("t_opt", "sum"), evaluaciones=("n_eval", "sum"), pliegues=("pliegue", "nunique")).reset_index()
agg["semilla"] = SEED
largo.to_csv(RESULTADOS / "tabla_maestra_por_pliegue.csv", index=False)
agg.to_csv(RESULTADOS / "tabla_maestra.csv", index=False)
print(f"{len(agg)} combinaciones ({(agg.tarea == 'clasificación').sum()} de clasificación, "
      f"{(agg.tarea == 'regresión').sum()} de regresión) y {len(largo):,} registros por pliegue.")

La tabla maestra (results/tabla_maestra.csv) contiene una fila por combinación con la media y la desviación de cada métrica del bucle externo, el tiempo total, el número de evaluaciones y la semilla; results/tabla_maestra_por_pliegue.csv agrega los hiperparámetros elegidos en cada pliegue externo. Las 112 combinaciones de clasificación, las 28 de regresión y las variantes del modelo original y de los métodos distribucionales comparten el mismo esquema.

Cómo reproducir los resultados#

El README del repositorio enumera los comandos en orden. Los cómputos costosos (la validación anidada de los 140 modelos y del modelo original) se guardan como resultados versionados en results/, y los cuadernos de este libro los leen y regeneran tablas y figuras; el código que los produce está en scripts/ y src/ y se ejecuta de principio a fin con los comandos del README. Las pruebas unitarias se ejecutan con python -m pytest.
